# 日音成分匹配器

一个给日音爱好者群用的「成分」匹配小站：大家把自己喜欢的歌手 / 乐队 / 企划勾进自己的成分表，站点用集合相似度算「和你最像的群友」，还支持包房分房、活动报名对接、喊话板等。

纯 Python 标准库 + 原生前端，**无任何第三方依赖**，一个 `server.py` 就能跑起来。

## 功能

- **成分表**：领域 + 细分两级词条，四档熟悉度（本命 / 常听 / 听过一些 / 只听过几首）
- **同好匹配**：加权 Dice 相似度 + 冷门权重，给出校准匹配度、两两配对、共同 / 独有词条
- **比成分**：输入对方 QQ，查看共同喜好、各自独有
- **排行榜**：领域榜 / 细分榜，前三名领奖台
- **包房**：勾选成员算「包房契合度」，支持按房数或每房人数自动分房，手动调房
- **活动**：对接看板 API，拉取报名名单 → 自动分房 → 分享图
- **喊话板**：24 小时一条、140 字，超 30 天进历史
- **其他**：留言（只对最像的那位可见）、热度趋势（30 分钟采样）、分享卡、深色模式、壁纸轮换、PWA

## 快速开始

```bash
# 1. 准备数据（首次运行会自动创建；或使用示例数据）
cp data.sample.json data.json

# 2. 启动（默认 8788 端口）
python server.py

# 打开 http://127.0.0.1:8788
```

可选环境变量：

| 变量 | 说明 | 默认 |
| --- | --- | --- |
| `JPM_PORT` | 监听端口 | `8788` |
| `JPM_DATA` | 数据文件路径 | `./data.json` |

后台管理：`/admin.html`。示例数据里的管理员口令是 `admin1234`，**上线前务必在后台改掉**（后台 → 数据与备份 → 重置口令）。

## 目录结构

```
server.py          # 后端：HTTP 服务 + 全部 API（标准库）
public/            # 前端
  index.html       # 主站
  app.js           # 主逻辑
  style.css        # 基础样式
  extra.css        # 站点样式（在 style.css 之后加载）
  admin.html/.js   # 后台
  pinyin.js        # 全拼搜索（按需加载）
  sw.js            # Service Worker
  walls/           # 壁纸（manifest.json + 图片）
data.json          # 数据（不提交）
data.sample.json   # 示例数据
tools/             # 运维脚本（重启、看门狗、迁移等）
```

## 数据与隐私

- `data.json`、`private/`、`backups/`、`archive/` 都在 `.gitignore` 里，**不要提交**：里面是群友 QQ、留言、喊话等私人内容。
- 词条、成员、喊话、趋势全部存在同一个 JSON 文件里，直接用文本编辑器也能改。
- 备份：数据文件每 10 分钟（有变更时）自动备份到 `backups/`，保留最近 30 份。

## 对接「看板」活动 API

活动页会从看板拉报名名单，需要配置密钥：

1. 新建 `private/qgroup-api-key.txt`，写入看板给的 API Key（一行，不要有空格）。
2. 或在启动前设置环境变量 `QGROUP_API_KEY`。
3. 后台「群友账号」里为每个群友填「看板 ID」，用于把报名数据对上成分表。

后续整合方向见[成分站与看板整合提案（讨论稿）](docs/qgroup-integration-proposal.md)，包括完整名单、账号对应、分房建议导出与看板确认的分工。建议导出／导入仍待双方讨论和实现，不改变当前只读对接方式。

## 部署

最简单的方式：本机 / 小服务器上 `python server.py`，前面挂个 ngrok 或 Nginx 反代即可。

- 生产建议用计划任务 / systemd 守护，`tools/watchdog.ps1` 是 Windows 下的自愈脚本。
- 改完 `server.py` 需要重启进程才生效（`tools/restart-server.ps1`）。
- 前端改动后记得把 `public/sw.js` 里的 `CACHE` 版本号 +1，否则浏览器会继续用旧缓存。

## 许可

个人项目，随便看看；如果要直接拿去做自己的群站，改改 `data.sample.json` 里的分类和初始词条就能用。
